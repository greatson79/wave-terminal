# Wave Terminal 0.2.3

- 패인 제목에 역할, 현재 모델, 좌석 번호와 CTX 사용률을 표시합니다. 첫 응답 전에는 CTX를 `—`로 표시합니다. 대화 기록에서 계산한 CTX는 `~`를 붙입니다.
- 사이드바에 Claude와 Codex의 5시간·7일 남은 사용량을 표시합니다. 측정이 없거나 창이 리셋되면 그 상태를 그대로 표시합니다.
- 새 부서 계정과 업데이트된 기존 부서 계정에 Claude 사용량 상태줄을 등록합니다. 기존 상태줄 명령은 이어서 실행합니다.
- 실행 중 `/model` 변경은 다음 Claude 응답이 기록된 뒤 제목에 반영됩니다. 구 데몬에서는 시작 시 모델을 표시하며, 부서 데몬 교대 뒤 현재 모델이 표시됩니다.
