# 0.3.5 업데이트 안내

열린 좌석이 있거나 좌석 수를 확인하지 못하면 본체 업데이트를 보류합니다. 「나중에」가 기본이며, 같은 대화상자에서 업데이트를 선택한 다음 좌석을 닫고 진행하는 단추를 눌러야 설치합니다. 업데이트 뒤 좌석은 새로 열립니다.

데몬 자동 전환 실패 안내에서 재부팅하면 해결된다는 약속을 없애고, 작업을 계속하면서 자세한 오류를 「도움 요청」으로 보내도록 안내합니다.

좌석 머리글은 이름만 간단히 표시하고, 작업 중·대기 중 상태는 사이드바의 각 좌석 옆에 표시합니다.

0.3.4 에서 올리는 이번 업데이트는 좌석이 닫힙니다(옛 판 코드가 업데이트를 실행하기 때문).
