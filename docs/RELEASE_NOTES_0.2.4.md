# Wave Terminal 0.2.4

앱의 Update 버튼을 누르면 0.2.4 로 바뀝니다.

## 고친 것
1. **Claude 창에 보낸 메시지가 안 들어가던 문제** — 다른 창을 눌렀다 돌아오기만 해도 「사람이 입력 중」으로 잘못 알아 전달을 막던 것을 고쳤습니다.
2. **(맥) 백그라운드 프로그램이 계속 다시 켜지던 문제** — 한 컴퓨터에서 하나만 돌도록 고쳤습니다.
3. **멈춘 에이전트 다시 켜기(`cys node-recover`)** — 마스터 창에서 다른 창의 멈춘 에이전트를 다시 켤 수 있습니다. 실패하면 이제 「실패」로 알려 줍니다(전에는 성공처럼 보일 때가 있었습니다).
4. **왼쪽 사용량 「측정 N분 전」이 멈춰 보이던 문제** — 가장 최근 값이 보이도록 고쳤습니다.
5. **도움 요청 보내기** — 「보내기」 한 번으로 바로 보내집니다.
6. 창 주소를 `s3` 나 `s:3` 처럼 짧게 써도 됩니다.

## 새로 생긴 것 — 창 이름 바꾸기
- 창 위쪽 제목을 **두 번 누르고** 이름을 쓴 뒤 **Enter** (지우려면 비우고 Enter). 제목에 마우스를 올리면 「두 번 눌러 이름 바꾸기」가 보입니다.
- 명령으로: `cys rename "이름"`
- 이름을 바꿔도 메시지 보내는 주소는 그대로입니다.

## 내가 바꾼 설정은 그대로
- 직접 만든 훅·스킬은 `~/.cys/local/` 에 두면 업데이트가 건드리지 않습니다.
- 고친 설정 파일이 있으면 새 판은 옆에 `.new` 로 놓입니다(`cys pack-merge` 로 합치기).

## 문제가 있으면
- 앱 안 「도움 요청」에 상황을 적어 보내 주세요.
