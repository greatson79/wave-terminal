macOS 명령 한 줄 설치

터미널에 붙여넣고 Return. 설치기가 설치팩을 받아 고정 SHA256으로 확인한 뒤 진행합니다.

최신 설치 명령은 Wave Terminal 설치 안내에서 확인하세요.

Windows 명령 한 줄 설치

PowerShell에 붙여넣고 Enter(관리자 권한 불필요). SmartScreen 경고 시 "추가 정보 → 실행".

최신 설치 명령은 Wave Terminal 설치 안내에서 확인하세요.
