# Wave Terminal 0.2.5

앱의 Update 버튼을 누르면 0.2.5 로 바뀝니다.

## 새로 생긴 것 — 위쪽 「설정 ▾」
- **글자·배경**: 배경색 · 폰트 · 창 제목 크기·굵기 · 제목 앞 색 점 · 터미널 글자 굵기 · 위쪽 단추 글자 굵기·크기. 바꾸면 열린 창 모두에 바로 적용됩니다.
- **위쪽 단추**: 단추마다 보이기/숨기기와 ▲▼ 순서 바꾸기. 숨긴 단추의 단축키는 그대로 됩니다. 「설정 ▾」 단추는 숨길 수 없습니다.
- **기본값 복원**: 구역마다 「이 구역만 기본값」, 전체는 「모두 기본값으로」.
- 전에 쓰던 「테마」 단추는 「설정 ▾」 안으로 들어갔습니다. 고르신 배경색과 폰트는 그대로 옮겨집니다.
- 바꾼 설정은 앱을 다시 켜도, 업데이트해도 그대로입니다.

## 고친 것
1. 업데이트 뒤 「직접 고친 파일은 그대로 두었습니다」 안내가 금방 사라지던 것 — 이제 「확인」을 누를 때까지 남습니다.
2. `cys run --scoped` 를 쓰면 「모르는 옵션」으로 거부되던 것 — 이제 그대로 실행됩니다.
3. 설치 중 「합칠 파일」 목록에 같은 파일이 두 번 나오던 것, 윈도우에서 경로가 잘려 보이던 것.

## 내가 바꾼 설정은 그대로
- 직접 만든 훅·스킬은 `~/.cys/local/` 에 두면 업데이트가 건드리지 않습니다.
- 고친 설정 파일이 있으면 새 판은 옆에 `.new` 로 놓입니다(`cys pack-merge` 로 합치기).

## 문제가 있으면
- 앱 안 「도움 요청」에 상황을 적어 보내 주세요.
